## 🔌 Enhanced Endpoints

### POST `/api/calendar/sync-full-plan`
**Sync complete 7-day workout + nutrition plan**

**Query Parameters:**
- `start_date` (optional): First day of plan (YYYY-MM-DD), defaults to today
- `preferred_time` (optional): Workout start time (HH:MM), defaults to 06:00

**Example:**
```bash
curl -X POST \
  "http://localhost:8000/api/calendar/sync-full-plan?start_date=2024-01-15&preferred_time=07:00" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

**Response:**
```json
{
  "success": true,
  "message": "✅ Synced 12 events to Google Calendar!",
  "summary": {
    "workout_events": 5,
    "meal_events": 7,
    "total_events": 12,
    "errors": []
  },
  "start_date": "2024-01-15"
}
```

---

### POST `/api/calendar/clear-events`
**Delete all ArogyaMitra calendar events**

**Query Parameters:**
- `days_ahead` (optional): Number of days to look ahead (default: 30)

**Example:**
```bash
curl -X POST \
  "http://localhost:8000/api/calendar/clear-events?days_ahead=60" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

**Response:**
```json
{
  "success": true,
  "message": "✅ Deleted 12 ArogyaMitra events",
  "deleted": 12
}
```

## 🎨 Calendar Service Functions

The enhanced calendar service provides these standalone functions:

### Core Functions:
- `get_auth_url()` - Generate OAuth URL
- `exchange_code_for_tokens(code)` - Get tokens from auth code
- `build_calendar_service(token_data)` - Build authenticated API client

### Event Management:
- `create_workout_event(...)` - Create single workout event
- `sync_workout_plan_to_calendar(...)` - Sync full 7-day workout plan
- `sync_meal_plan_to_calendar(...)` - Sync full 7-day meal plan
- `delete_arogyamitra_events(...)` - Delete all ArogyaMitra events

### Legacy Support:
- `CalendarService` class - Backward compatible wrapper
- `calendar_service` singleton - For existing code

## 💡 Usage Examples

### Python Backend Usage

```python
from app.services.calendar_service import (
    build_calendar_service,
    sync_workout_plan_to_calendar,
    sync_meal_plan_to_calendar,
    delete_arogyamitra_events
)

# Build service
service = build_calendar_service({
    "token": user.calendar_access_token,
    "refresh_token": user.calendar_refresh_token
})

# Sync workout plan
result = sync_workout_plan_to_calendar(
    service=service,
    workout_plan=plan_data,
    start_date="2024-01-15",
    preferred_time="06:00"
)
print(f"Created {result['created']} workout events")

# Sync meal plan
meal_result = sync_meal_plan_to_calendar(
    service=service,
    nutrition_plan=nutrition_data,
    start_date="2024-01-15"
)
print(f"Created {meal_result['created']} meal reminders")

# Clean up old events
delete_result = delete_arogyamitra_events(service, days_ahead=30)
print(f"Deleted {delete_result['deleted']} events")
```
