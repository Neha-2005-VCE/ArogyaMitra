# 🎉 Welcome to ArogyaMitra - Your AI Fitness Companion!

## 🚀 Quick Start (2 Steps)

### 1️⃣ Start Backend
```bash
cd ArogyaMitra/backend
python -m uvicorn main:app --reload --port 8000
```

### 2️⃣ Start Frontend (New Terminal)
```bash
cd ArogyaMitra/frontend
npm run dev
```

### 3️⃣ Open Browser
Go to: **http://localhost:5173**

## 🐛 Troubleshooting

### Frontend won't start?
```bash
cd ArogyaMitra/frontend
npm install
npm run dev
```

### Backend won't start?
```bash
cd ArogyaMitra/backend
pip install -r requirements.txt
python -m uvicorn main:app --reload --port 8000
```

### Port already in use?
- Backend: Use `--port 8001` instead
- Frontend: Vite will suggest alternative port
